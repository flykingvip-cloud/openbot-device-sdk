# 设备平台配对与设备控制 API

这是后续工作，不是 OpenBot 冻结契约的一部分。当前草稿没有实现这组 HTTP API。

OpenBot 的 OpenAPI 里没有配对挑战字段，也没有客户端注册接口。设备归属和一次性配对挑战由设备平台在进入 OpenBot 授权流程之前完成。连接器不得把 `pairChallenge`、`pairingCode` 或其他自造字段放进 `/api/integrations/v1` 的请求。

计划中的设备控制面只给 OpenBot 的服务客户端调用，不接受浏览器自行声明的用户、租户或数字人 id：

- 能力发现
- 一次性配对挑战
- 按授权列出设备
- 应用绑定
- 绑定状态
- 停止 / 撤销
- 状态同步
- 健康检查

这些路由和本仓库已有的认领码、短时连接凭证是设备平台自己的。它们不改冻结字段名，也不代替 grant exchange。生产 OTA 和批量刷机仍然关闭。
