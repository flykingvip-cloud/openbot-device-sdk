# openbot-b2

消费者：`integrations/openbot-b2`。

本地 stand-in：`POST /v1/device/sessions`（B2）。请求体只用冻结字段名：

- `authorizationRef`
- `bindingVersion`
- `digitalHumanId`
- `deviceId`

四项必须和当前绑定一致，包括版本号。rebind 之后旧的 `authorizationRef` 不能再开会话。响应带回绑定里的 `assistant.*`，不重命名、不删键。

这条路径仍然是本地 stand-in。不要对 `upbeyond/openbot` 或作废针 `68e062e` 发会话请求。
